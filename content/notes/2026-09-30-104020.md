You know what's cool about AI? Getting it to tune your keyboard driven machine with context of your actual keyboard (I know this can be done without AI, but a quick win for a lifetime of benefit).

```text
 PREFIX = hold Z (Ctrl) + tap Space        [L1] = hold ` thumb
                                           [L2] = hold Bksp thumb
 PANES
   |          split side-by-side     [L2] + right pinky home
   -          split top/bottom       [L2] + right inner index
   h j k l    move left/down/up/right
   H J K L    resize (hold Space for Shift, keeps repeating)
   z          zoom pane on/off
   x          close pane
   q          show pane numbers

 WINDOWS
   c          new window
   1-9        jump to window         [L1] + top row
   n / p      next / previous
   ,          rename window
   w          pick from list

 SESSIONS
   d          detach   (reattach: tmux a)
   s          pick session
   $          rename session
   C-s / C-r  save / restore now (autosaves every 15 min)
   r          reload config

 COPY MODE
   [          enter                  [L2] + right middle home
   v  y       select, then copy
   q          leave

 ?  this help     /  look up what a key does     :  command
                    q to close
```
